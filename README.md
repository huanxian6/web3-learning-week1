## 学习路线

1. **Python 基础**：变量与数据类型 → 条件语句 → 循环 → 函数 → 列表 / 字典
2. **区块链原理**：区块链 ≠ 比特币、哈希、公私钥、共识机制、智能合约
3. **Web3 生态**：DeFi / NFT / GameFi / Layer2 / DePIN 等赛道认知
4. **工具链**：VS Code、Git、GitHub、Remix、MetaMask
